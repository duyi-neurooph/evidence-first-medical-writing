## 1. 随机对照试验

核心链条：

`注册/方案 → 招募 → 同意 → 随机序列 → 分配隐藏 → 干预 → 盲法/结局评估 → 样本流 → ITT 主分析 → 主要结局`

优先检查：

- 主要结局和时间点是否预设。
- 随机方法不是“用随机数排序后硬切两半”。
- 区组、分层或整群随机的理由与分析相匹配。
- 随机后排除、交叉和缺失不会被藏进 mITT。
- 摘要先报告主要结局，再报告有限的次要和安全性结果。
- 阴性主要结局不由阳性亚组翻盘。

若要核对当前规范，查最新版 CONSORT 及其相关扩展。

## 2. 非劣性与等效性研究

不能从普通优效试验的 `P>0.05` 得出疗效相当。

必须明确：

- 为什么需要非劣或等效问题。
- 对照是否具有可证明的历史疗效。
- 非劣/等效界值及临床理由。
- 成功判定使用的 CI 规则。
- 样本量和多重性。
- ITT 与 PP 结果是否一致支持。
- 是否允许在预设条件下检验优效。

治疗执行差、交叉和不依从可能把结果推向“无差异”，对非劣性结论尤其危险。

## 3. 观察性比较研究

先明确是队列、病例对照、横断面还是其他设计，再写分组。

至少说明：

- 数据来源、时间范围和连续性。
- 暴露/治疗怎样发生。
- 结局定义、时间窗和获得方式。
- 混杂因素的选择逻辑。
- 缺失、失访和选择机制。
- 粗结果、调整结果和敏感性分析。

使用 `associated with` 等关联语言。倾向评分、多变量回归或大型样本不能自动提供因果结论。

## 4. 诊断准确性研究

明确：

- 临床使用场景与疑似人群。
- 指数检测和参考标准。
- 两者的时间间隔与治疗介入。
- 判读者是否相互盲法。
- 无法判定和缺失结果怎样处理。
- 预设阈值还是数据驱动阈值。
- 完整 2×2 数据、敏感度、特异度及 CI。

只纳入已确诊病例和健康对照通常不能代表真实诊断场景。需要当前规范时查最新版 STARD。

## 5. 预测模型

区分开发、内部验证、外部验证和模型更新。

检查：

- 预测时点和使用人群。
- 候选变量在预测时点可得。
- 事件数与模型复杂度。
- 缺失和连续变量处理。
- 过拟合控制和验证方法。
- 校准、区分度、总体性能及临床效用。
- 完整模型或可实施工具是否提供。

不要把多因素“危险因素”表改名为预测模型。需要当前规范时查最新版 TRIPOD 及相关模型偏倚评估工具。

## 6. 系统评价与荟萃分析

先有明确问题，再决定是否合并。

检查：

- 方案和注册。
- 可复现的数据库、时间、检索式和补充检索。
- 双人筛选、提取和冲突解决。
- 合适的偏倚风险工具。
- 人群、干预、结局、随访和设计的可合并性。
- 效应指标、模型、异质性和敏感性分析。
- 小样本效应、发表偏倚和选择性结果报告的评估及其局限。
- 证据确定性/可信度评价与结论措辞一致。
- 研究层面结论没有超过原始研究质量。

标题写 `systematic review and meta-analysis` 时，正文应同时体现系统评价过程与统计合并；不能只拼森林图。需要当前规范时查最新版 PRISMA。

## 7. 个案报告

“罕见”不是充分价值。先说明病例能改变什么诊断、治疗或风险认识。

按时间顺序组织：

1. 主诉和关键背景。
2. 对鉴别诊断有用的阳性与阴性信息。
3. 检查、诊断推理和备选诊断。
4. 干预、剂量/过程和理由。
5. 结局、随访和患者视角（适用时）。
6. 临床启示及不确定性。

保护患者身份，取得适用的发表同意。需要当前规范时查最新版 CARE。

## 8. Correspondence 与 Letter

先核对期刊当前定义、时限、字数、图表和参考文献限制。

用极短结构：

`具体主张 → 直接证据 → 为什么重要 → 克制结论`

批评已发表论文时聚焦可核验的方法、数据和解释，不攻击作者动机。若提出新分析，说明数据来源和局限。

## 9. 描述性与实验研究

描述性研究：

- 明确描述对象、抽样框、时间和测量层级。
- 不把表达差异、相关变化或横断面结果直接写成机制。
- 标题和结论不扩大到未研究的人群、组织或时间。

实验研究：

- 写清模型、对照、随机、盲法、重复、排除和关键操作参数。
- 方法以可复现为标准，既不堆无信息步骤，也不删除关键细节。
- 区分生物学重复与技术重复。
- 图像处理、排除和归一化规则据实报告。

需要当前报告规范时，按研究类型查相应官方清单，不把历史文章中的规则当作最新版。

## 10. 本 playbook 未充分覆盖的类型

研究方案、定性/混合方法、经济学评价、动物研究和其他专门类型，只应用本 skill 的通用可信度、结构与语言原则；不要把一般临床比较研究模板强套其上。

需要时先识别真实设计，再查询相应最新版官方规范和方法资源，例如研究方案、定性研究、卫生经济学或动物研究的专门清单。若问题涉及专门设计或分析判断，明确建议由相应方法学专家核查。
