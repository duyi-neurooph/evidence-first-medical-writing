# 审校与交付检查表

## 全文审校顺序

### 第 0 轮：权限、隐私与材料边界

- 是否包含患者姓名、生日、住院号、影像标记、联系方式或可重新识别身份的组合信息？
- 个案、图像和可识别资料是否取得适用的发表同意？
- 稿件、审稿信、回复函和未公开数据是否属于用户有权处理的材料？
- 是否有人要求冒充作者、隐瞒错误、伪造预设性或公开指控未经调查认定的个人？

若有隐私、授权或诚信风险，先处理 P0，不继续扩散敏感材料。

### 第 1 轮：只看骨架

只读题目、摘要、各级标题、图表题、讨论首段和结论：

- 能否复述一句话核心命题？
- 研究问题、主要结局和主要时间点是什么？
- 研究类别最多允许什么结论？
- 图表顺序是否讲出同一条故事线？
- 题目、摘要和结论是否都围绕预设主要结局？

若不能，不进入逐句润色。

### 第 2 轮：方案与可信度链

- 研究时段、招募、随访、数据库锁定、投稿和发表时间是否可能。
- 回顾性、前瞻性、随机、队列、病例对照、诊断、预测等标签是否与真实流程一致。
- 伦理批准、同意/豁免、注册时间、方案版本和分析计划是否据实。
- 主要结局是否与方案、注册、样本量依据、结果和结论一致。
- 所有终点变更、阈值变更、追加分析和方案偏离是否说明发生时点及理由。
- 受试者从入组到每个分析集的路径能否逐步核对；每个分析集的人数和排除理由是否可解释。彼此重叠的分析集不得机械相加。
- 随机序列、分配隐藏、盲法、执行角色和破盲是否可理解。
- 缺失数据机制、处理方法和敏感性分析是否与问题相称。
- 数据、图片、作者名单或分析错误是否透明更正，并说明对结论的影响。

发现疑点时要求作者核实原始材料，不替作者编解释，也不在没有证据时断言造假。

### 第 3 轮：设计—分析—结论链

- 研究设计能否回答问题，还是只能生成假说或描述关联？
- 样本量依据是否围绕预设主要结局和有意义差异。
- 优效、非劣和等效设计是否使用相应假设、界值、分析集和 CI 判定。
- 重复测量、聚类、配对和多中心结构是否在模型中处理。
- 调整变量是否基于临床机制、时间顺序和预设策略，而非只看单因素 P 值。
- 多重终点、多时间点、亚组、阈值搜索和模型选择是否控制或透明披露多重性。
- 预测模型是否区分开发与验证，并报告校准、判别和过拟合控制。
- 观察性研究是否避免把回归、倾向评分或大样本写成因果证明。
- `P>0.05` 是否被误写成相等、安全、无效或“证明没有差异”。
- 是否同时解释效应方向、大小、置信区间、临床意义和统计不确定性。

### 第 4 轮：结果链

- 主要结局先报告，且包含定义、时间点、比较方向和完整数字。
- 百分比有分子和分母；连续变量的汇总方式与分布相容。
- 组别顺序、单位、时间点、参照组和小数位在正文、表图和摘要中稳定。
- 互斥分组人数之和与总人数相符，事件分子不超过相应分母；重叠分析集不机械相加。
- 效应指标明确估计对象、参照组和比较方向；信息缺失时不凭 OR/HR 大小自行推断。
- 效应量、95% CI 与精确 P 值相互相容；可疑时标为统计核查。
- 主要、次要、亚组、敏感性和探索性分析有清楚标签。
- 阴性主要结果没有被显著次要或探索性结果取代。
- 结果只陈述观察到什么，不提前解释机制或临床意义。
- 表和图能独立理解，并交代分母、误差线、分析集、缩写和统计比较。

### 第 5 轮：论证与引用链

对每条关键主张检查：

- 这是事实、解释、机制假说、建议还是规范要求？
- 引文是否直接支持这条主张，而不是只提到同一主题？
- 原始研究与综述的证据层级是否被准确表达？
- 是否把二手引文、旧指南或单篇研究写成学界共识？
- 是否出现“很多研究表明”“众所周知”等不可核查替代语？
- 易变化的指南、报告规范、期刊政策和统计建议是否使用当前官方来源？
- 引用中的人群、干预、结局、时间和设计是否被偷换？

### 第 6 轮：讨论与证据边界

- 开头概括主要发现，而不是重写引言或只报显著性。
- 与既有研究比较时，先比较可比性，再解释一致或不一致。
- 机制解释明确标为解释或假说，与设计和数据强度匹配。
- 局限具体说明它可能怎样改变估计、解释或推广，而非例行公事。
- 外部效度考虑地点、抽样框、人群、干预执行和随访条件。
- 结论只回答主要问题，不使用超出设计的因果、疗效或实践建议。
- 不用“样本量大”“首次研究”或结尾的积极语气掩盖关键不确定性。

### 第 7 轮：叙事与语言

- 每段首句能说明本段任务；每段只推进一个逻辑单元。
- 一句话只承载一个主要命题，并列内容处于同一层级。
- 代词、缩写、组别、分母和比较方向无需读者回查。
- 连接词真实反映因果、转折、递进或并列关系。
- 中文转英文后保留原事实和逻辑，不逐字复制中文长句结构。
- 删除重复、空泛、夸大、广告式表达和与核心命题无关的内容。
- 时态、术语、药名、单位、数字格式和标点按目标期刊统一。

## 红旗分级

| 级别 | 典型问题 | 处理 |
|---|---|---|
| P0 可信度阻断项 | 伦理晚于入组且无解释；注册与论文主要终点未经解释地矛盾；要求隐瞒数据/图片错误；可识别病例无发表同意。P0 是暂停核实信号，不是造假判断 | 暂停常规润色，核实原始材料并保留审计轨迹 |
| P1 研究逻辑 | 疗效问题却用不能回答疗效的设计；因果措辞超过观察性设计、识别假设和敏感性分析所支持的范围；核实后确认只是叙事层级上的终点错位；普通优效试验宣称等效 | 重建命题、修正分析定位或降低结论 |
| P2 结构与自明性 | 复现信息不足；摘要无主要结局数字；A/B 组；关键缩写未定义或有歧义；样本流不清；图表不能独立理解 | 补齐信息并重组结构 |
| P3 语言与格式 | 长句层级混乱；缩写过多或格式不统一；术语、时态、冠词或标点不一致 | 在 P0–P2 解决后精修 |

## 审稿回复矩阵

每条意见填写：

| 字段 | 内容 |
|---|---|
| 审稿人显性问题 | 原意见的可核查要点 |
| 底层顾虑 | 可信度、设计、复现、解释、完整性或表达 |
| 立场 | 同意 / 部分同意 / 有证据地不同意 |
| 行动 | 修改、核查、补充分析或解释；未完成时不能写成已完成 |
| 结果 | 实际发现；未完成时使用占位符 |
| 影响 | 对主要结果、解释和结论是否产生影响 |
| 稿件位置 | 页/行/段占位符或最终准确位置 |
| 同步项 | 摘要、正文、表图、补充材料、注册或回复函是否同步 |

不得虚假写“完全同意”，不得为获得显著性删除有效病例或搜索阈值，也不得编造页码、行号和分析结果。

## 交付模板：诊断

```markdown
核心命题卡
- 研究问题：
- 主要结局：
- 证据边界：
- 读者应记住：

首要判断
1. [P0/P1/P2/P3] 位置：……
   - 问题：
   - 影响：
   - 最小改法：
   - 需谁确认：

建议顺序
1. 必须先改……
2. 然后重组……
3. 最后润色……

作者需核实
- ……
```

## 交付模板：改写

```markdown
主要诊断
- ……

修改稿
……

关键改动
- 删除/移动……，因为……
- 把……改为……，以明确……

待作者补充
- [待作者补充：主要结局定义和时间点]
```

## 交付模板：投稿前检查

| 必须改 | 建议改 | 作者核实 |
|---|---|---|
| 影响可信度、主命题或结论的事项 | 改善自明性、层级和效率的事项 | 不能由稿件或公开资料确认的事实 |

## 最终一致性清单

- [ ] 题目准确反映人群、比较、结局和真实研究类别。
- [ ] 摘要可独立理解，主要结局有定义、时间点和数字。
- [ ] 引言沿最短路径导向当前证据缺口。
- [ ] 方法足以判断可靠性和复现，并与注册/方案一致。
- [ ] 样本流、分析集、缺失、多重性和任何方案偏离透明。
- [ ] 结果按主要、次要、探索层级报告。
- [ ] 图表与正文数字、单位、分母和组别顺序一致。
- [ ] 引文直接支持对应主张，易变化规则使用当前官方来源。
- [ ] 讨论解释主要发现并具体说明局限。
- [ ] 结论没有超出设计、主要结果和置信区间。
- [ ] 伦理、注册、作者贡献、数据可用性和利益冲突据实。
- [ ] 没有编造、隐藏或悄悄改变任何事实和统计结果。
