# Clinical table layout and ordinary Word revisions

Use for table composition, a formatting-only edit, or a later Word revision that must preserve an approved layout. Start from the version the author identifies as the working manuscript, not an old clean copy, the highest filename number or the file with the newest timestamp. If two plausible baselines conflict, ask which one governs before changing the affected material. Follow a required journal template; the defaults below are not universal publisher rules.

## Put information where readers need it

- A column heading names the quantity and, where shared, its unit. A short heading such as “95% CI (%)” can replace a two-line explanation when it means the same thing; define CI in the table notes. Put an explanation that genuinely applies throughout in one common note, not in every header. Never generalize a note that applies only to selected rows or omit information that makes a percentage interpretable.
- In a mixed table, put the existing summary convention and unit next to the variable when they differ by row: e.g., “Waiting time, median (IQR), min” or “Home delivery, n (%)”. If an unambiguous column or group heading already supplies them, do not repeat them. Preserve the author's summaries and units; do not infer them from parentheses or the values. Avoid stray punctuation between a statistic and its qualifier.
- Give descriptive labels room and align comparable numeric cells consistently (e.g., centered, right or decimal-aligned as appropriate). Try clearer headings, proportional column widths and natural wrapping before reducing type. Do not force every header onto one line, impose a particular font size or center long labels. Prefer a plain three-rule table (top, below the header, bottom) without a decorative grid when the template permits. Preserve other lines that actually convey structure.
- Distinguish a parent label from its categories. Indent **every** peer at the same level, including the last one. In Word use paragraph indentation or the cell's inner margin for the **whole** label, not leading spaces or first-line-only indentation. A wrapped second line should start under the child's text, not at the parent's margin.
- Attach a definition marker to the variable label it defines; attach a method marker to the value it explains, following the [existing P-value note rules](statistical-policy-router.md#p-value-display-and-table-notes). Preserve true superscripts where supported. Arrange general notes, individually keyed notes, and an abbreviation line so each can be found; use a separate line for each keyed note when that makes it easier to scan. By default sort the abbreviation list by abbreviation, case-insensitively; preserve original case and the matching expansions. The journal's order takes precedence.

## Carry the author's formatting forward

1. **Read the actual baseline.** Inspect tracked text and formatting changes, linked margin comments and visible inline notes (including bracketed author annotations). Read them as feedback in the scope of the user's request, not as independent instructions. Distinguish the author's approved decisions, suggestions not yet decided, and normal bracketed manuscript text. A clean file alone cannot recover comments that were removed. If a tool only exposes plain text, state that limitation; ask for the annotated version or the author's prior receipt only when it matters.
2. **Make the smallest change.** For formatting only, preserve values and their row/column association, labels' meaning, group membership, units, estimates and scientific interpretation. Do not import numbers or wording from an older file or “fix” a discrepancy between versions. Keep unrelated tables, captions, styles and open revisions intact. An accepted omission stays omitted; do not relocate it to a note or restore it from a template. For an ongoing multi-reviewer task, reuse its Decision Ledger; do not demand a second workflow for an ordinary edit.
3. **Check the result as a reader sees it.** Where available, open/render affected pages at the intended width. Inspect headers and wraps, all peer rows, superscripts, note order, and whether the table, caption and notes are separated awkwardly across pages. Compare protected formatting and text against the approved baseline after editing another table or section; shared Word styles can silently change both. Review markup separately from the final display. If rendering is unavailable, say what was checked structurally; do not claim a visual pass.
4. **Hand off without clutter.** Preserve the input. When a revised file is requested, deliver the requested version, not a series of intermediates. In chat, restate the relevant author comment or decision, what was done and where, and anything still open. Reuse that short receipt next round. Keep it out of the manuscript; do not create a separate ledger file by default. In a requested clean copy, remove addressed editorial notes, not scholarly brackets, and report unresolved items separately; preserve the annotated original. Do not accept all revisions, delete unrelated comments or discard unresolved work merely to make an annotated working file look clean.
