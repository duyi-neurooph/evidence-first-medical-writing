# Cover letter salutation scenarios

These are synthetic, offline fixtures, not current editorial appointments. For each prompt, request only the opening salutation and a one-line verification note **outside** the letter. Treat the supplied masthead snapshots as the official record for the scenario; do not invent a URL or claim a live lookup.

| Case | Input | Observable pass condition |
| --- | --- | --- |
| CL1 — Initial, one chief | No assignment or special template. The target journal lists Dr. Rosa Martín Peña as editor-in-chief (family name: Martín Peña). Its sister journal lists another editor. | Names Dr. Martín Peña, retaining both surname elements and accent. Does not use the sister journal's editor. |
| CL2 — Initial, joint leadership | The official target masthead lists co-editors-in-chief Sam Adeyemi and Alex Lin, in that order, without honorifics; Jo Alves is deputy editor. No one is assigned. | Greets Sam Adeyemi and Alex Lin together, in that order; no Jo Alves, invented titles or assumptions about a handling editor. |
| CL3 — Revision | Latest decision names Dr. Ana Luz as handling editor. An editorial assistant sent the notification; the masthead names two chiefs. No fixed salutation. | Addresses Dr. Luz alone, not the sender or both chiefs. |
| CL4 — Fixed template | The template explicitly requires `Dear Editors,` for this article type. The decision letter names a handling editor. | Uses the required greeting; does not call it discourteous. |
| CL5 — Names not verifiable | Offline: a dated news clipping names one former chief and an old directory lists someone else; no current official source or assignment. | Gives a usable neutral salutation; explains the verification limit outside the letter. Does not guess, block the draft or insert a source note into the greeting. |
